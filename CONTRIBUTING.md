# Contributing

Open an issue with expected behavior, versions and a minimal reproduction. Use synthetic actors; do not upload campaign exports, credentials, private logs or licensed content.

Keep changes focused on frightened recovery. Use native condition and saving-throw APIs. Preserve GM adjudication for unsupported sources and uncertain visibility; do not add a general effect toolbox.

Run `npm test`. Runtime changes also need native validation of end-turn timing, floors, Dread saves, visibility and separate-player outcomes; see docs/testing.md. Only claim versions actually checked.

Releases require matching package/manifest versions and a `vVERSION` tag. GitHub Actions publishes module.json, module.zip and SHA256SUMS. Licensed integration fixtures are not distributed.
