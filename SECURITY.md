# Security

Use GitHub's private vulnerability-reporting feature when available, or privately contact the maintainer through their profile. Do not post credentials or private campaign data in public issues.

Only the active GM resolves automatic recovery. Target owners roll native saves; GM override controls are GM-only. Results must match the pending request's exact token, check type and DC and come from an owner. No socket service is added. Foundry's normal trusted-user permission model applies.
